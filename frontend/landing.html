How it works

From dispute to decision in under a second

No overnight batch jobs, no fragile prompt chains. A deterministic LangGraph state machine drives each case through a pipeline of specialised executors.

01

Ingest any reason code

Webhook arrives — HMAC-SHA256 verified, dispute record created, FSM launched as a background task. HTTP 200 returned in under 5s.

02

Classify in 5ms, $0

TF-IDF cosine similarity maps any reason code to 4 semantic families — fraud, non-receipt, service, policy. No API call, no rate limit, no prompt drift.

03

Gather in parallel

Logistics, security, and CRM executors fire concurrently via asyncio. API timeouts always route to human review — never hallucinate evidence.

04

Fight or accept, honestly

LightGBM returns a calibrated fight_confidence. Below threshold → accept. Above → compile rebuttal PDF with only verified evidence. High-value always goes to a human.
